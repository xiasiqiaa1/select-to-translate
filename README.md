# 选中翻译 (Select-to-Translate)

一个极简的 Chrome 浏览器扩展 — 选中网页文字后自动弹出翻译弹窗，支持中英互译。

## 功能

- **选中即翻译**：鼠标选中文字后自动弹出翻译结果，无需右键或快捷键
- **中英互译**：自动检测文字语言方向（含中文→译英文，纯英文→译中文）
- **安全渲染**：使用 `textContent` 赋值，防御 XSS 攻击
- **自适应定位**：弹窗自动避开屏幕边缘，翻译完成后自动修正位置
- **溢出滚动**：长文本翻译结果限制最大高度 400px，超出可滚动
- **超时处理**：网络异常时 8 秒超时提示，不卡死
- **免费 API**：基于 MyMemory 翻译接口，无需注册或密钥

## 安装

1. 下载本项目到本地
2. 打开 Chrome，地址栏输入 `chrome://extensions/`
3. 开启右上角「开发者模式」
4. 点击「加载已解压的扩展程序」，选择本项目的文件夹
5. 完成！去任意网页选中文字即可看到翻译弹窗

## 使用

- 在任意网页上**选中一段文字**，弹窗自动出现
- 点击弹窗右上角 **×** 或弹窗外部任意位置关闭
- 选中新文字会自动替换旧弹窗

## 技术实现

| 模块 | 说明 |
|------|------|
| 触发 | `mouseup` 事件监听，100ms 延迟等待选区更新 |
| 语言检测 | 正则 `[\u4e00-\u9fa5]` 判断是否含中文 |
| 翻译 API | MyMemory (`api.mymemory.translated.net`) |
| 超时 | `AbortController`，8 秒超时 |
| XSS 防御 | 用户文本仅通过 `textContent` 赋值 |
| 定位 | `position: fixed` + 边界检测 + 翻转 + 兜底修正 |
| 溢出 | `max-height: min(400px, 60vh)` + `overflow-y: auto` |
